# LoginMonitor Project

## Overview
The LoginMonitor project is a Python application that parses, analyzes, and reports on system login logs. It tracks user behavior, calculates success and failure metrics, identifies multi-IP usage, finds peak traffic hours, and generates security alerts for accounts with suspicious failed attempts.

## How to Run
1. Ensure you have Python installed on your system.
2. Open your terminal or command prompt, navigate to the folder where `login_monitor.py` is saved.
3. Run the script with the following command:
   ```bash
   python login_monitor.py
